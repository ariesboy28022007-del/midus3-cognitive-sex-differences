# Obtaining the data

The source respondent-level data are **not distributed in this repository**.

Obtain the original public-use archives from ICPSR, subject to registration and applicable terms:

- MIDUS 3 Cognitive Project, ICPSR 37095, version 3: https://doi.org/10.3886/ICPSR37095.v3
- MIDUS 3 Survey Project 1, ICPSR 36346, version 7: https://doi.org/10.3886/ICPSR36346.v7

Download each in **Stata** format, preserving the archive filenames:
`ICPSR_37095-V3.zip` and `ICPSR_36346-V7.zip`.

In Google Colab, upload both archives before running the notebook.

Do not upload ZIP archives, extracted respondent-level data, or direct identifiers to a public GitHub repository.
